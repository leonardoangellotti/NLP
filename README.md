# README

## NLP Project

This repository contains code and notebooks related to seq2seq with attention mechanism.

### Features

* Text preprocessing
* Tokenization & embeddings
* NLP model experiments
* output visualization and evaluation

### Getting Started

Clone the repository:

```bash
git clone https://github.com/leonardoangellotti/NLP.git
cd NLP
```

and run the notebook.

### Purpose

This repository is intended for learning, experimentation, and NLP project development.
